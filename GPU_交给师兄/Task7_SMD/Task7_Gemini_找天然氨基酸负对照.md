# 找"纯天然 L 氨基酸 + 低渗透"环肽负对照 — 给 Gemini 的提示词

（把下面整段复制进 Gemini。**同时把附件 CSV 传给它**：`负对照候选_低渗透筛选用.csv`，路径见本文件同目录。）

---

我有一份从 CycPeptMPDB 导出的**低渗透环肽**数据表（已附 CSV，字段：CycPeptMPDB_ID / Permeability / Monomer_Length / Sequence / SMILES / Source，已按渗透率 ≤ −6.0 过滤）。我要从中挑一个"**SMD 负对照**"：跑分子动力学应**穿不过**细胞膜，用于证明我的预测模型能区分高/低渗透。

## 硬性筛选条件（必须全部满足）
1. **纯天然、标准 L 型氨基酸**：不能含 D-氨基酸、不能含 N-甲基化、不能含任何非标准单体。
   - 数据里 `Sequence` 的编码规则，请严格按下面解码：
     - **单个大写字母** = 天然 L 型标准氨基酸：A,R,N,D,C,Q,E,G,H,I,L,K,M,F,P,S,T,W,Y,V（注意是大写单字母）。
     - 以 **小写 `d`/`l` 开头**（如 `dA`、`dP`、`dL`）或有 `d` 前缀 = **D-型/非 L** → 排除。
     - 含 **`me`/`Me`/`NMe`/`Me_`** 前缀（如 `meL`、`Me_dL`）= **N-甲基化** → 排除。
     - **多字母专名**（如 `Abu,Sar,Aib,Orn,Dab,Nle,Cha,bHph,Nal,Bn_Gly,Pr_Gly,Cys(...),_NH2` 等）= 非标准单体 → 排除。
   - 只有当一条肽的**每一个残基**都是"单大写标准氨基酸字母"时才算合格。
2. **低渗透**：Permeability 尽量低（≤ −8 优先；−10 是低于检测限的赋置值，可用但要注明）。
3. **环肽**：SMILES 首尾成环（检查 SMILES 是否有环闭）。大小 6–10 个残基。
4. **适合 MD**：全疏水或中性更好（无强电荷），越简单越好做膜动力学。

## 你要做的
1. 用你读 CSV（或写代码）的能力，先**逐条解码并筛出"全部残基都是天然 L 单字母"的条目**，给出筛完后剩多少条。
2. 如果"纯天然 L + 很低渗透"在库里很少或没有，**如实告诉我实际数量**，不要硬把含 D/甲基/非标准的肽当成"天然氨基酸"塞给我。并给备选建议。
3. 从合格者里挑 **3–5 个最适合做 SMD 负对照**的，按适合度排序；推荐 1 个首选并给理由（结构简单、尺寸合适、能代表"模型预测的低渗透"）。
4. 对每个候选输出一张核对表：CycPeptMPDB_ID、Permeability、长度、翻译成 1 字母的序列（如 "LPALPLF"）、SMILES、**残留基逐一定性"天然 L?"**、以及是否环肽。
5. 给一个"我该把 SMILES/序列拿去跑 SMD"的最终建议分子。

## 输出要求
- 先给一句结论（库里合格数多少 / 推荐用谁），再给候选表和理由。
- 不确定某项时明确说，别猜、别编造某个分子存在。

（背景：这是 SCI 返修，审稿人要求补一个"非渗透肽"的 SMD 负对照；跑 MD 的人会用 CHARMM-GUI/GROMACS，所以越标准越好参数化。跑之前我会把分子核对表再人工确认一次。）
