## 这次为什么不会再来一次「45 小时只出 1 个任务」

| 上次的病根 | 这次的修法 |
|---|---|
| **子进程参数被覆盖**：3 个消融任务各自都跑了全部 3 个变体（`base_args` 里的 `--variants` 盖掉了任务自己的设置）→ 3 倍重复劳动 + 并发写同一批文件 | 参数顺序反过来，任务自己的设置生效 |
| **一个任务能跑几天**：`loso` 单任务 36 个子任务、估计 117 小时 | 任务拆到「单折」；加 `--job-hours 3` 超时自动跳过 |
| **收尾永远轮不到**：出表/出图要等所有 GPU 任务结束 | `--max-hours 5` 硬上限，到点结束训练并**照常收尾** |
| **失败看不见**：日志只写「请检查」 | 失败/超时自动把该任务日志最后 15 行打进看守日志，并汇总到 `logs/失败记录.md` |
| 心跳只报「完成」不报「失败」 | 心跳同时报 `失败/跳过 N 个`，并列出是哪些 |
| 诊断脚本被当成修复脚本（本次的误会） | `诊断.sh` 末尾现在会明确写：**本脚本只读，要动手请跑 `重启_6小时版.sh`** |
